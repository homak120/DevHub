# AEP Dev Hub

AEP Dev Hub is an internal VS Code extension that serves as the central hub for AEP engineering tools, workflow launchers, and approved extension integrations.

## MVP Scope
### Phase 1
- VS Code extension shell
- Sidebar UI
- Tool catalog
- Launch existing extensions
- Install npm packages
- Pull artifacts from Artifactory

### Phase 1.5
- Pull files from Bitbucket
- Populate workspace files
- Conflict preview and manual fallback

## Initial Supported Tools
- AEP UI Copilot Extension
- FarmFix CLI
- AEP MCP Connector
- SmartADA

## Tech Stack
- TypeScript
- VS Code Extension API
- Static JSON registry
- Generated TypeScript types
- VSIX distribution
