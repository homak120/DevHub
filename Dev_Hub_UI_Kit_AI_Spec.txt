========================================================================
1. HIGH-LEVEL OVERVIEW
========================================================================

The Dev Hub extension lives in the VS Code sidebar (Activity Bar >
"Dev Hub" / tools icon). It has three views that share the same 380px-wide
sidebar column:

  - MainPanel     "AEP DEV HUB: TOOL CATALOG"  (default)
  - SettingsPanel "AEP DEV HUB: SETTINGS"      (opened via gear)
  - AIMarketplace "DEV HUB > AI MARKETPLACE"   (opened via rocket row)

Clicking a marketplace source opens a centered overlay modal on top of
the editor (dark radial purple, gradient title, category tiles).

All colors derive from VS Code theme tokens (--vscode-*) so the UI
adapts to light + dark themes. Fonts: 'Segoe UI' (ui) and
'SF Mono'/'Menlo' (mono) stacks. Icons are Microsoft codicons.

========================================================================
2. DESIGN TOKENS
========================================================================

All tokens are declared in colors_and_type.css and prefixed --dh-*.
They reference VS Code theme vars so they respect the user's theme.

Key colors (dark theme resolved values):
  --dh-bg-panel       #252526   sidebar background
  --dh-bg-hover       #2a2d2e   row hover
  --dh-bg-selected    #37373d   row selected
  --dh-fg             #cccccc   primary foreground
  --dh-fg-dim         #9d9d9d   secondary foreground
  --dh-fg-faint       #6b6b6b   tertiary / version labels
  --dh-fg-section     #cccccc   section headers (uppercase)
  --dh-border         #3a3a3a   separators
  --dh-focus          #007fd4   focus ring
  --dh-link           #3794ff   links / interactive blue
  --dh-danger         #f14c4c   destructive text
  --dh-danger-bg      #5a1d1d   destructive bg

Accent (action buttons + type tags, NOT theme-derived):
  sky-500  #0ea5e9   solid button / count pill
  sky-400  #38bdf8   gradient top + tag border/text
  sky-700  #0284c7   button border

Section count pills: background #0ea5e9, text #ffffff, border-radius 999,
min-width 18px, height 18px.

Type scale (all use --dh-font-ui = Segoe UI stack):
  title bar      11px / 600 / uppercase / letter-spacing .08em
  card title     13px / 600
  card desc      12px / 400 / --dh-fg-dim
  type tag       10px / 700 / uppercase / letter-spacing .04em
  badge count    10px / 600
  meta           11px / 400 / --dh-fg-dim

Monospace (--dh-font-mono = SF Mono stack) used for:
  - repo paths in marketplace sidebar  (10px / --dh-fg-dim)
  - resource names in overlay detail view (13px)

Spacing:
  row vertical padding      4-6px
  card padding              10px 10px 8px 12px
  card margin               4px 8px
  title bar padding         10px 12px
  search padding            10px 12px
  section header padding    8px 12px 6px

Radii:
  card / row                4px
  icon tile                 6px (32x32)
  overlay modal             12px
  button                    4px

Transitions:
  row bg                    120ms
  chevron rotate            120ms
  pin rotate                120ms

/* Dev Hub UI Kit — shared primitives */

function Checkbox({ checked, indeterminate, onChange, ariaLabel }) {
  return (
    <span
      role="checkbox"
      aria-checked={indeterminate ? "mixed" : checked}
      aria-label={ariaLabel}
      tabIndex={0}
      onClick={(e) => { e.stopPropagation(); onChange && onChange(!checked); }}
      onKeyDown={(e) => {
        if (e.key === " " || e.key === "Enter") {
          e.preventDefault();
          e.stopPropagation();
          onChange && onChange(!checked);
        }
      }}
      style={{
        width: 14, height: 14, borderRadius: 2, flex: "none",
        display: "inline-flex", alignItems: "center", justifyContent: "center",
        border: `1px solid ${(checked || indeterminate) ? "var(--dh-check-selected-border)" : "var(--dh-check-border)"}`,
        background: (checked || indeterminate) ? "var(--dh-check-selected-bg)" : "var(--dh-check-bg)",
        color: "var(--dh-check-selected-fg)",
        cursor: "pointer",
        boxSizing: "border-box",
      }}
    >
      {checked && !indeterminate && (
        <i className="codicon codicon-check" style={{ fontSize: 10, color: "var(--dh-check-selected-fg)" }} />
      )}
      {indeterminate && (
        <span style={{ display: "block", width: 8, height: 1.5, background: "var(--dh-check-selected-fg)" }} />
      )}
    </span>
  );
}

function IconButton({ codicon, title, onClick }) {
  return (
    <button className="dh-icon-button" title={title} aria-label={title} onClick={onClick}>
      <i className={`codicon codicon-${codicon}`} style={{ fontSize: 14 }} />
    </button>
  );
}

function DangerButton({ icon = "trash", children, onClick }) {
  return (
    <button className="dh-button dh-button--danger" onClick={onClick}>
      <i className={`codicon codicon-${icon}`} style={{ fontSize: 14 }} />
      {children}
    </button>
  );
}

function SectionLabel({ children }) {
  return (
    <div style={{
      padding: "8px 10px 2px",
      fontFamily: "var(--dh-font-ui)",
      fontSize: "var(--dh-font-size-label)",
      letterSpacing: "var(--dh-letter-spacing-label)",
      textTransform: "uppercase",
      fontWeight: 600,
      color: "var(--dh-fg-section)",
    }}>
      {children}
    </div>
  );
}

function TitleBar({ breadcrumb, onClose }) {
  return (
    <div className="dh-title-bar">
      <div style={{
        display: "flex", alignItems: "center", gap: 6,
        fontFamily: "var(--dh-font-ui)", fontSize: 11, fontWeight: 600,
        letterSpacing: "0.08em", textTransform: "uppercase",
        color: "var(--dh-fg-section)",
      }}>
        {breadcrumb.map((b, i) => (
          <React.Fragment key={i}>
            {i > 0 && <span style={{ opacity: 0.5, fontWeight: 400 }}>›</span>}
            <span style={{ opacity: i === breadcrumb.length - 1 ? 1 : 0.6 }}>{b}</span>
          </React.Fragment>
        ))}
      </div>
      {onClose && <IconButton codicon="close" title="close" onClick={onClose} />}
    </div>
  );
}

Object.assign(window, { Checkbox, IconButton, DangerButton, SectionLabel, TitleBar });

function App() {
  const [theme, setTheme] = React.useState("dark");
  const [view, setView] = React.useState("main"); // "main" | "settings" | "marketplace"
  const [overlayMP, setOverlayMP] = React.useState(null);
  const [groups, setGroups] = React.useState(() => JSON.parse(JSON.stringify(DH_SAMPLE_GROUPS)));
  const [, tick] = React.useReducer((x) => x + 1, 0);

  const vars = theme === "dark" ? DARK_THEME_VARS : LIGHT_THEME_VARS;
  const varString = Object.entries(vars).map(([k, v]) => `${k}: ${v};`).join(" ");

  const clearAll = () => {
    const fresh = JSON.parse(JSON.stringify(DH_SAMPLE_GROUPS));
    fresh.forEach((g) => g.tools.forEach((t) => { t.on = false; }));
    setGroups(fresh);
  };

  return (
    <div style={{ height: "100vh", display: "flex", flexDirection: "column", background: vars["--vscode-editor-background"] }}>
      <style>{`:root { ${varString} }`}</style>
      <div style={{ flex: 1, display: "flex", minHeight: 0 }}>
        <ActivityBar
          theme={theme}
          onThemeToggle={() => setTheme(theme === "dark" ? "light" : "dark")}
        />
        <div style={{
          width: 380, borderRight: "1px solid var(--dh-border)",
          display: "flex", flexDirection: "column", minHeight: 0,
          background: "var(--dh-bg-panel)",
        }}>
          {view === "main" && (
            <MainPanel
              onOpenSettings={() => setView("settings")}
              onOpenMarketplace={() => setView("marketplace")}
            />
          )}
          {view === "settings" && (
            <SettingsPanel
              groups={groups}
              onClose={() => setView("main")}
              onClearAll={clearAll}
              forceRerender={tick}
            />
          )}
          {view === "marketplace" && (
            <AIMarketplaceList
              marketplaces={MARKETPLACES}
              onOpen={(m) => setOverlayMP(m)}
              onBack={() => setView("main")}
            />
          )}
        </div>
        {/* fake editor area */}
        <div style={{
          flex: 1, background: "var(--vscode-editor-background)",
          display: "flex", alignItems: "center", justifyContent: "center",
          color: "var(--dh-fg-faint)", fontFamily: "var(--dh-font-mono)", fontSize: 12,
        }}>
          editor area — click the gear in the sidebar to open settings
        </div>
      </div>
      {overlayMP && (
        <MarketplaceOverlay marketplace={overlayMP} onClose={() => setOverlayMP(null)} />
      )}
      {/* fake status bar */}
      <div style={{
        height: 22, background: theme === "dark" ? "#007acc" : "#0078d4",
        color: "#ffffff", fontFamily: "var(--dh-font-ui)", fontSize: 12,
        display: "flex", alignItems: "center", padding: "0 10px", gap: 12, flex: "none",
      }}>
        <span>main</span>
        <span>Dev Hub</span>
      </div>
    </div>
  );
}

ReactDOM.createRoot(document.getElementById("root")).render(<App />);
