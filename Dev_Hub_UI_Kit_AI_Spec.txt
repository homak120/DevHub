========================================================================
1. HIGH-LEVEL OVERVIEW
========================================================================

The Dev Hub extension lives in the VS Code sidebar (Activity Bar >
"Dev Hub" / tools icon). It has three views that share the same 380px-wide
sidebar column:

  - MainPanel     "AEP DEV HUB: TOOL CATALOG"  (default)
  - SettingsPanel "AEP DEV HUB: SETTINGS"      (opened via gear)
  - AIMarketplace "DEV HUB > AI MARKETPLACE"   (opened via rocket row)

Clicking a marketplace source opens a centered overlay modal on top of
the editor (dark radial purple, gradient title, category tiles).
The overlay supports type-ahead search across all categories, drilling
into a category, and opening a resource for preview.

All colors derive from VS Code theme tokens (--vscode-*) so the UI
adapts to light + dark themes. Fonts: 'Segoe UI' (ui) and
'SF Mono'/'Menlo' (mono) stacks. Icons are Microsoft codicons.

========================================================================
3. PANEL ANATOMY
========================================================================

MainPanel - 380px wide
  title bar with refresh + gear, search input, AI Marketplace nav row,
  collapsible sections (FAVORITES, AVAILABLE, MOBILE PROMPTS) with cyan
  count pills. ToolCard has 32x32 icon tile, title+desc, sky gradient
  action button top-right, type tag + meta + status row, pin bottom-right.

AIMarketplace sidebar list (rocket row in main panel)
  title bar with back button, "SOURCES" label, list rows of marketplaces
  (repo icon + name + mono repo path + count + chevron), "Add source"
  footer.

Overlay modal - 1100px x 780px, centered with three view states:

HOME view:
  - 44px gradient title (purple -> pink) + 14px subtitle
  - search input + Repo button row (40px tall, max-width 560)
  - empty query: 3-col grid of category tiles (icon + name + count + desc)
  - non-empty: SearchResults list

CATEGORY view (drill-in):
  - back -> home
  - 28px icon + 30px title + count
  - vertical list of resources. Each row:
      [icon] mono filename
             desc - by author
      [N files / 1 file]   [stars]   [Install gradient pill]   <-- install lives HERE

RESOURCE view (clicked from a result OR a category list):
  - Top: back + icon + name + meta + star
    (NO Install button on the resource preview page)
  - single-file: full-width FilePreview
  - multi-file: 240px FileTree on left + FilePreview on right

========================================================================
5. AI MARKETPLACE: SEARCH + RESOURCE PREVIEW
========================================================================

Type-ahead search (OverlayHome)
  - Match fields: name, desc, categoryName, author (case-insensitive substring)
  - Capped at 20 results
  - Results show icon + mono name (highlighted) + desc (highlighted) +
    outlined category tag + file count
  - Empty-state: 'No results for "<query>".'

Resource preview (ResourcePreview)
  Shape decision is driven by resource.kind:
    "single" -> one full-width FilePreview pane (no tree)
    "multi"  -> 240px FileTree on left, FilePreview on right

  Header (always present):
    [back] [category icon] mono filename
                           category - by author - "single file" | "N files"
    [stars]
    -> NO Install button here. Install lives on the category list rows.

  FileTree (multi only):
    - 240px wide, dark purple bg, "FILES" label
    - Folders sort first then alphabetical
    - Selected file: purple-tinted bg + 2px left border #a855f7
    - Click folder toggles expand; click file selects it

  FilePreview:
    - Top strip: file icon + path (mono) + extension chip on the right
    - Body: <pre> with whiteSpace:pre-wrap, mono, dark bg
    - Md files render slightly brighter than code files

State:
  - MarketplaceOverlay holds a single "view" object: {kind, ...}
  - Esc backs out one level
  - Selected file resets to files[0] when a new resource is chosen

Mock corpus (RESOURCE_CORPUS in AIMarketplace.jsx):
  - Up to 6 resources per (marketplace, category) pair
  - Single-file categories: Instructions, Prompts, Snippets, Hooks
  - Multi-file categories:  Agents, Skills, Plugins, Tools, Workflows,
                            MCP Servers, Extensions, Integrations,
                            Samples, Tool Use, Evals, Learning Hub
  - Multi-file scaffolding: README.md, config.json, instructions.md,
                            src/main.ts, src/helpers.ts,
                            prompts/system.md, prompts/user.md

/* Dev Hub UI Kit — shared primitives */

function Checkbox({ checked, indeterminate, onChange, ariaLabel }) {
  return (
    <span
      role="checkbox"
      aria-checked={indeterminate ? "mixed" : checked}
      aria-label={ariaLabel}
      tabIndex={0}
      onClick={(e) => { e.stopPropagation(); onChange && onChange(!checked); }}
      onKeyDown={(e) => {
        if (e.key === " " || e.key === "Enter") {
          e.preventDefault();
          e.stopPropagation();
          onChange && onChange(!checked);
        }
      }}
      style={{
        width: 14, height: 14, borderRadius: 2, flex: "none",
        display: "inline-flex", alignItems: "center", justifyContent: "center",
        border: `1px solid ${(checked || indeterminate) ? "var(--dh-check-selected-border)" : "var(--dh-check-border)"}`,
        background: (checked || indeterminate) ? "var(--dh-check-selected-bg)" : "var(--dh-check-bg)",
        color: "var(--dh-check-selected-fg)",
        cursor: "pointer",
        boxSizing: "border-box",
      }}
    >
      {checked && !indeterminate && (
        <i className="codicon codicon-check" style={{ fontSize: 10, color: "var(--dh-check-selected-fg)" }} />
      )}
      {indeterminate && (
        <span style={{ display: "block", width: 8, height: 1.5, background: "var(--dh-check-selected-fg)" }} />
      )}
    </span>
  );
}

function IconButton({ codicon, title, onClick }) {
  return (
    <button className="dh-icon-button" title={title} aria-label={title} onClick={onClick}>
      <i className={`codicon codicon-${codicon}`} style={{ fontSize: 14 }} />
    </button>
  );
}

function DangerButton({ icon = "trash", children, onClick }) {
  return (
    <button className="dh-button dh-button--danger" onClick={onClick}>
      <i className={`codicon codicon-${icon}`} style={{ fontSize: 14 }} />
      {children}
    </button>
  );
}

function SectionLabel({ children }) {
  return (
    <div style={{
      padding: "8px 10px 2px",
      fontFamily: "var(--dh-font-ui)",
      fontSize: "var(--dh-font-size-label)",
      letterSpacing: "var(--dh-letter-spacing-label)",
      textTransform: "uppercase",
      fontWeight: 600,
      color: "var(--dh-fg-section)",
    }}>
      {children}
    </div>
  );
}

function TitleBar({ breadcrumb, onClose }) {
  return (
    <div className="dh-title-bar">
      <div style={{
        display: "flex", alignItems: "center", gap: 6,
        fontFamily: "var(--dh-font-ui)", fontSize: 11, fontWeight: 600,
        letterSpacing: "0.08em", textTransform: "uppercase",
        color: "var(--dh-fg-section)",
      }}>
        {breadcrumb.map((b, i) => (
          <React.Fragment key={i}>
            {i > 0 && <span style={{ opacity: 0.5, fontWeight: 400 }}>›</span>}
            <span style={{ opacity: i === breadcrumb.length - 1 ? 1 : 0.6 }}>{b}</span>
          </React.Fragment>
        ))}
      </div>
      {onClose && <IconButton codicon="close" title="close" onClick={onClose} />}
    </div>
  );
}

Object.assign(window, { Checkbox, IconButton, DangerButton, SectionLabel, TitleBar });

function makeResourceCorpus() {
  const out = [];
  const authors = ["octocat", "torvalds", "gaearon", "tj", "sindresorhus", "addyosmani", "kentcdodds", "yyx990803"];
  const descs = [
    "Opinionated starter with sensible defaults.",
    "Lightweight, zero-config, ships today.",
    "Battle-tested in production at scale.",
    "Minimal dependencies, fast cold-start.",
    "Type-safe from top to bottom.",
    "Works offline; sync when online.",
    "Composable primitives; drop-in ready.",
    "Focus on DX: error messages that help.",
  ];
  let uid = 0;

  const singleFileCats = new Set(["Instructions", "Prompts", "Snippets", "Hooks"]);
  const multiFileCats  = new Set(["Agents", "Skills", "Plugins", "Tools", "Workflows", "MCP Servers", "Extensions", "Integrations", "Samples", "Tool Use", "Evals", "Learning Hub"]);

  for (const m of MARKETPLACES) {
    for (const c of m.categories) {
      const n = Math.min(c.count, 6); // cap to 6 shown
      for (let i = 0; i < n; i++) {
        const slug = `${c.name.toLowerCase().replace(/\s+/g, "-")}-${String(i + 1).padStart(2, "0")}`;
        const isSingle = singleFileCats.has(c.name);
        const author = authors[(uid + i) % authors.length];
        const desc = descs[i % descs.length];
        const resource = {
          uid: `r${uid++}`,
          marketplaceId: m.id,
          marketplaceName: m.name,
          categoryName: c.name,
          categoryIcon: c.icon,
          categoryColor: c.color,
          slug,
          name: slug,
          author,
          stars: [1240, 832, 540, 298, 176, 92, 44, 12][i % 8],
          desc,
          kind: isSingle ? "single" : "multi",
          files: isSingle ? buildSingleFile(c.name, slug) : buildMultiFiles(c.name, slug),
        };
        out.push(resource);
      }
    }
  }
  return out;
}

function buildSingleFile(catName, slug) {
  const ext = catName === "Snippets" ? "ts" : "md";
  const name = `${slug}.${ext}`;
  const content = ext === "md"
    ? `# ${slug}\n\n> Category: ${catName}\n\nA reusable ${catName.toLowerCase()} template.\n\n## Usage\n\nDrop into your repo and reference from your agent config.\n\n## Example\n\n\`\`\`\nYou are an expert ${catName.toLowerCase()} assistant.\nFollow the team style guide at all times.\nFavor small, composable changes over large rewrites.\n\`\`\`\n`
    : `// ${slug}.${ext}\n// Category: ${catName}\n\nexport function run(input: string): string {\n  // TODO: customize\n  return input.trim();\n}\n`;
  return [{ path: name, type: "file", content }];
}

function buildMultiFiles(catName, slug) {

function highlight(text, q) {
  if (!q) return text;
  const idx = text.toLowerCase().indexOf(q);
  if (idx < 0) return text;
  return (

      <span style={{ background: "rgba(168, 85, 247, 0.25)", color: "#f2eefa" }}>
        {text.slice(idx, idx + q.length)}
      </span>
      {text.slice(idx + q.length)}
    </>
  );
}

function FileTree({ files, selectedPath, onSelect }) {
  // Build a nested structure from flat paths
  const root = React.useMemo(() => {
    const r = { name: "", path: "", children: new Map(), file: null };
    for (const f of files) {
      const parts = f.path.split("/");
      let node = r;
      parts.forEach((part, i) => {
        const isLeaf = i === parts.length - 1;
        const key = parts.slice(0, i + 1).join("/");
        if (!node.children.has(key)) {
          node.children.set(key, {
            name: part,
            path: key,
            children: new Map(),
            file: isLeaf ? f : null,
          });
        }
        node = node.children.get(key);
      });
    }
    return r;
  }, [files]);

  return (
    <div style={{
      width: 240, flex: "none",
      background: "rgba(15, 8, 22, 0.7)",
      borderRight: "1px solid #2a1f3e",
      overflowY: "auto",
      padding: "12px 0",
    }}>
      <div style={{
        fontSize: 10, letterSpacing: "0.08em", textTransform: "uppercase",
        color: "#8a7fa6", fontWeight: 600,
        padding: "0 16px 8px",
      }}>
        Files
      </div>
      <TreeNode node={root} depth={0} selectedPath={selectedPath} onSelect={onSelect} />
    </div>
  );
}

function TreeNode({ node, depth, selectedPath, onSelect }) {
  const [open, setOpen] = React.useState(true);
  const children = [...node.children.values()].sort((a, b) => {
    // folders first
    const aFolder = a.file == null;
    const bFolder = b.file == null;
    if (aFolder !== bFolder) return aFolder ? -1 : 1;
    return a.name.localeCompare(b.name);
  });

  return (
    <>
      {node.name !== "" && (
        <div
          onClick={() => (node.file ? onSelect(node.file) : setOpen(!open))}
          style={{
            display: "flex", alignItems: "center", gap: 6,
            padding: `4px ${16}px 4px ${16 + depth * 14}px`,
            cursor: "pointer",
            fontFamily: "var(--dh-font-mono)", fontSize: 12,
            color: selectedPath === node.path ? "#f2eefa" : "#c4bcd6",
            background: selectedPath === node.path ? "rgba(168, 85, 247, 0.18)" : "transparent",
            borderLeft: selectedPath === node.path ? "2px solid #a855f7" : "2px solid transparent",
          }}
          onMouseEnter={(e) => {
            if (selectedPath !== node.path) e.currentTarget.style.background = "rgba(168, 85, 247, 0.08)";
          }}
          onMouseLeave={(e) => {
            if (selectedPath !== node.path) e.currentTarget.style.background = "transparent";
          }}
        >
          {node.file ? (
            <i className="codicon codicon-file" style={{ fontSize: 12, color: "#9a92b0" }} />
          ) : (
            <>
              <i
                className="codicon codicon-chevron-right"
                style={{
                  fontSize: 10, color: "#9a92b0",
                  transform: open ? "rotate(90deg)" : "rotate(0)",
                  transition: "transform 120ms",
                }}
              />
              <i className="codicon codicon-folder" style={{ fontSize: 12, color: "#c4a7f3" }} />
            </>
          )}
          <span style={{ overflow: "hidden", textOverflow: "ellipsis", whiteSpace: "nowrap" }}>
            {node.name}
          </span>
        </div>
      )}
      {(node.name === "" || open) && children.map((child) => (
        <TreeNode
          key={child.path}
          node={child}
          depth={node.name === "" ? 0 : depth + 1}
          selectedPath={selectedPath}
          onSelect={onSelect}
        />
      ))}
    </>
  );
}

      ))}

        onClick={onThemeToggle}

        }}>
        <i className={`codicon codicon-${theme === "dark" ? "color-mode" : "symbol-color"}`} style={{ fontSize: 18 }} />
      </div>
    </div>
  );
}

function App() {
  const [theme, setTheme] = React.useState("dark");
  const [view, setView] = React.useState("main"); // "main" | "settings" | "marketplace"
  const [overlayMP, setOverlayMP] = React.useState(null);
  const [groups, setGroups] = React.useState(() => JSON.parse(JSON.stringify(DH_SAMPLE_GROUPS)));
  const [, tick] = React.useReducer((x) => x + 1, 0);

  const vars = theme === "dark" ? DARK_THEME_VARS : LIGHT_THEME_VARS;
  const varString = Object.entries(vars).map(([k, v]) => `${k}: ${v};`).join(" ");

  const clearAll = () => {
    const fresh = JSON.parse(JSON.stringify(DH_SAMPLE_GROUPS));
    fresh.forEach((g) => g.tools.forEach((t) => { t.on = false; }));
    setGroups(fresh);
  };

  return (
    <div style={{ height: "100vh", display: "flex", flexDirection: "column", background: vars["--vscode-editor-background"] }}>
      <style>{`:root { ${varString} }`}</style>
      <div style={{ flex: 1, display: "flex", minHeight: 0 }}>
        <ActivityBar
          theme={theme}
          onThemeToggle={() => setTheme(theme === "dark" ? "light" : "dark")}
        />
        <div style={{
          width: 380, borderRight: "1px solid var(--dh-border)",
          display: "flex", flexDirection: "column", minHeight: 0,
          background: "var(--dh-bg-panel)",
        }}>
          {view === "main" && (
            <MainPanel
              onOpenSettings={() => setView("settings")}
              onOpenMarketplace={() => setView("marketplace")}
            />
          )}
          {view === "settings" && (
            <SettingsPanel
              groups={groups}
              onClose={() => setView("main")}
              onClearAll={clearAll}
              forceRerender={tick}
            />
          )}
          {view === "marketplace" && (
            <AIMarketplaceList
              marketplaces={MARKETPLACES}
              onOpen={(m) => setOverlayMP(m)}
              onBack={() => setView("main")}
            />
          )}
        </div>
        {/* fake editor area */}
        <div style={{
          flex: 1, background: "var(--vscode-editor-background)",
          display: "flex", alignItems: "center", justifyContent: "center",
          color: "var(--dh-fg-faint)", fontFamily: "var(--dh-font-mono)", fontSize: 12,
        }}>
          editor area — click the gear in the sidebar to open settings
        </div>
      </div>
      {overlayMP && (
        <MarketplaceOverlay marketplace={overlayMP} onClose={() => setOverlayMP(null)} />
      )}
      {/* fake status bar */}
      <div style={{
        height: 22, background: theme === "dark" ? "#007acc" : "#0078d4",
        color: "#ffffff", fontFamily: "var(--dh-font-ui)", fontSize: 12,
        display: "flex", alignItems: "center", padding: "0 10px", gap: 12, flex: "none",
      }}>
        <span>main</span>
        <span>Dev Hub</span>
      </div>
    </div>
  );
}

ReactDOM.createRoot(document.getElementById("root")).render(<App />);
